# PortoMind 产品功能说明

> 文档范围：根据当前前端页面与交互整理  
> 更新日期：2026-08-25

## 1. 产品简介

PortoMind 是一款面向个人用户的自托管投资组合管理工具，用于维护资产资料、查看行情、记录交易、跟踪持仓，并根据目标配置生成再平衡建议。

当前产品适合单用户在可信网络中使用，定位为投资记录与辅助决策工具，不直接连接券商，也不会自动完成真实证券交易。

## 2. 功能导航

前端左侧提供以下功能入口：

| 模块 | 主要用途 |
| --- | --- |
| Dashboard | 查看产品能力简介与使用入口提示 |
| 价格 | 查看各资产最近价格、指定日期价格和单个资产的历史价格 |
| 组合管理 | 创建和维护投资组合，查看目标、交易、持仓及再平衡信息 |
| 交易记录 | 记录、编辑和删除买入或卖出流水 |
| 资产管理 | 维护可用于组合与交易的资产基础资料 |
| 日志 | 查询服务运行日志和后台任务日志 |

## 3. 主要功能

### 3.1 Dashboard

- 展示产品欢迎信息及主要能力说明。
- 引导用户通过左侧菜单进入组合、交易、资产和日志模块。

### 3.2 资产管理

- 查看资产列表及资产总数。
- 按代码、名称或标签搜索资产。
- 按代码、名称、市场、类型、启用状态、关注状态或创建时间排序。
- 支持每页 10、20 或 50 条的分页浏览。
- 新增、编辑和删除资产；删除前会要求用户确认。
- 维护以下资产信息：
  - 代码、名称；
  - 市场：美股、加股、上海、深圳、中国基金；
  - 币种：USD、CAD、CNY；
  - 类型：股票、ETF、基金、债券、现金；
  - 标签、启用状态、关注状态。
- 启用的资产可以进入交易和组合目标资产选择；关注状态用于标记重点资产，与启用状态相互独立。
- 可从资产列表直接进入该资产的价格历史页。

### 3.3 价格查询

- 默认查看各资产最近一条价格数据。
- 可选择具体日期，查看该日全部价格记录。
- 支持手动刷新当前查询结果和分页浏览。
- 可进入单个资产的历史价格页面：
  - 按年月筛选；
  - 通过折线图查看价格走势；
  - 通过表格查看每日价格；
  - 支持分页浏览。

说明：当前前端只提供价格数据查询，不提供手工录入或主动触发行情同步的按钮。

### 3.4 交易记录

- 分页查看全部交易流水。
- 展示交易日期、资产代码、资产类型、买卖方向、份额、价格和所属组合。
- 创建买入或卖出交易，并填写：
  - 所属组合；
  - 资产；
  - 交易类型；
  - 交易日期；
  - 交易份额与价格；
  - 备注。
- 选择资产后自动带出市场、币种和资产类型。
- 支持编辑和删除已有交易。
- 交易会参与组合持仓数量、平均成本、剩余成本和盈亏计算。

### 3.5 组合管理

#### 组合列表与基本信息

- 以卡片形式查看组合名称、描述、类型和基础币种。
- 新建、编辑和删除组合。
- 组合类型包括活钱、稳健和长期；基础币种包括 CNY、CAD 和 USD。
- 删除组合时会提示该组合、其全部交易及再平衡记录将一并删除且不可撤销。

#### 目标配置

- 创建或编辑组合时，可从已启用资产中添加目标资产并设置目标比例。
- 支持添加或移除多个目标资产。
- 目标资产不可重复，非空目标配置的比例合计必须为 100%。
- 在组合详情中对比每项资产的目标比例和当前实际比例。

#### 组合交易

- 在组合详情内查看仅属于当前组合的交易记录。
- 支持分页浏览；交易的新增、编辑和删除统一在“交易记录”模块操作。

#### 持仓概览

- 查看资产代码、币种、持有份额、平均成本、剩余成本、最新价格、总金额、未实现盈亏和盈亏比。
- 支持按资产代码搜索。
- 支持按总金额或盈亏比升降序排列。
- 支持分页浏览。

#### 持仓历史

- 查看持仓市值与剩余成本的历史趋势图和明细表。
- 可查看全部持仓或指定资产。
- 支持日、周、月三种时间粒度。
- 不同币种分别展示，不进行汇率换算或跨币种合计。

### 3.6 再平衡

#### 阈值设置

- 可分别启用或停用以下检查条件：
  - 绝对偏离阈值；
  - 相对偏离阈值；
  - 距上次执行的时间间隔。
- 偏离阈值范围为 0%～100%，时间间隔最少为 1 天。

#### 检查与建议

- 检查当前组合是否触发再平衡，并查看各资产的目标比例、当前比例、偏离程度及触发项。
- 生成建议前可输入可投入现金、固定手续费、比例手续费和卖出税率。
- 查看每项建议的买卖方向、数量、成交额、预计手续费、预计税费和调整后比例。
- 查看卖出净所得、买入可用资金、剩余现金及相关警告。
- 通过双层饼图对比当前比例与建议执行后的比例。
- 页面会恢复已有的待确认建议，并展示最近一次已执行记录。

#### 执行与历史

- 用户确认后，系统按“先卖后买”将建议转换为内部交易流水。
- 分页查看再平衡记录的时间、模式、建议数、执行交易数、反向交易数和状态。
- 已执行记录可撤销；撤销会创建反向交易。
- 已撤销记录可重新生成一份待确认建议。

说明：这里的“执行”只是在 PortoMind 内创建交易记录，不代表向券商提交真实订单。

### 3.7 日志查看

- 在 Server Log 与 Task Log 之间切换。
- 按日期和日志级别（Info、Warn、Error）筛选。
- 查看时间戳、级别、Trace ID 和日志消息。
- 支持分页浏览，便于排查接口请求、价格同步和后台任务问题。

## 4. 推荐使用流程

1. 在“资产管理”中创建并启用需要跟踪的资产。
2. 在“组合管理”中创建组合，设置基础币种和目标资产比例。
3. 在“交易记录”中录入历史及后续买卖流水。
4. 在组合详情中查看当前持仓、盈亏、实际比例和历史趋势。
5. 配置再平衡阈值，检查偏离并生成调整建议。
6. 核对资金、费用和建议明细后，决定是否在系统内执行并留存记录。
7. 需要排查数据同步或服务异常时，进入“日志”模块查询。

## 5. 当前边界与注意事项

- 当前没有登录、退出登录或多用户权限能力，仅适合部署在可信网络。
- 顶部搜索框、用户头像和左侧“退出登录”目前为界面占位，尚无实际交互。
- Dashboard 当前为功能引导页，不包含资产汇总或收益统计看板。
- 当前不提供汇率换算；不同币种金额保持原币种展示，组合基础币种不用于自动折算。
- 当前不连接券商，不执行真实交易，也不构成投资建议。
- 行情同步由后台任务负责；前端仅查询已经保存的价格数据。
- 删除组合会级联删除相关交易及再平衡记录，操作不可撤销。
