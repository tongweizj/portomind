# 用户场景索引（SCENARIOS）

> **本文唯一负责**：用户场景（SCN）清单与导航。场景是**可选**层——只有需要交代「用户在什么情境下、为什么做这件事」时才建，简单需求可跳过，直接写 User Story。
>
> **单一归属**：场景的叙述正文只写在 `SCN-xxx.md` 里；本索引只汇总 + 链接，不抄正文。场景不参与 Story / Task 状态流转，本索引仅保存链接与摘要。
>
> **与需求链路的关系**：`产品目标（PRODUCT.md / PRD） → 用户场景（本目录） → 用户故事（stories/） → 任务（tasks/）`。场景到故事是**一对多**：一个场景可拆出多条 US，一条 US 也可不挂场景（直接源于 PRD/FS）。

## 目录即状态

场景文件不分状态目录——场景是描述性文档，一旦写入即定稿，后续只增改不流转。需要表达「已弃用」时，在文件头部加一行 `> 状态：已弃用（<原因>）`，不移动文件。

## 编号

- 格式：`SCN-<3位序号>-<slug>.md`，例如 `SCN-001-business-trip-receipt.md`。
- 序号全局递增、不复用；即使场景弃用，编号也保留。
