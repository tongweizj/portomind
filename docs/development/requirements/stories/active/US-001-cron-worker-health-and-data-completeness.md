## 2. 用户问题与价值

**用户与场景：** 每日查看 PortoMind 的使用者，希望确认价格、完整性检查、提醒、汇率和再平衡分发是否正常。

**当前问题：** 仅查看运行成功日志不能判断数据是否真正齐全；逐行翻日志成本高，缺结果也容易被误读为正常。本段描述来源 Spec 的问题背景，并非本次对实时系统的重新实测。

**用户故事：** 作为每日使用 PortoMind 的用户，我希望打开日志频道就能区分五类定时任务的运行结果与数据完整性，并查看价格缺失及关键异常摘要，以便判断数据是否可信、哪里需要进一步排查。

**交付后的改善：** 无需先翻原始日志即可查看五类任务摘要；价格目标日、应采/已采和缺失清单可见；缺数据或缺结果不会显示成“全部正常”。

## 3. 本次范围与产品规则

### 本次交付

- Spec P0 的 C-01～C-05：看板入口、只读聚合快照、价格数据态展示、系统状态色，以及结果数据契约。
- 五类任务的首屏摘要、运行态与数据态区分、快照时间、首次加载及手动刷新。
- 价格目标市场日与应采/已采、缺失标的；完整性、提醒、汇率、再平衡分发的真实结果摘要。
- 保留原服务器日志与任务日志视图；数据缺失、空态、跳过及错误有明确表达。

### 范围外事项

- P1：C-06 的超期未成功运行提示、C-07 的 /logs/rebalance 详情页、C-08 的带任务/日期一键下钻；分别留给后续 Story。
- P2：历史趋势与 launchDate 治理入口；不承诺本次交付完整 Spec。
- 调度控制、重算业务数据、自动轮询、执行/撤销/重做再平衡，以及组合域提醒详情。
- 修复汇率方向、价格回补、symbol 不一致等既有业务缺陷；本 Story 负责真实暴露状态，不宣称已修复这些问题。
- 已完成原型不等同于真实功能交付；TASK-061 仅作为参考，不代替运行验收。

### 必要规则与约束

- /logs 只读；刷新只重新读取快照，不触发任务或写入。
- 数据态是完成度主信号，运行成功不证明数据齐全；缺失值、无结果、未运行、零目标分别表达，不以零或成功兜底。
- 前端展示后端派生口径，不自行计算业务目标日或数据完整性。
- 完成 TASK-057 是本 Story 完整验收的必要条件；开发中允许显示契约未就绪，不允许仅靠降级状态宣布本 Story 完成。
- RUNNING 僵尸识别沿用已交付聚合接口的口径；与本次范围外的 P1“超期未成功运行”提示区分，不能把二者混为同一需求。

## 4. 验收条件

| 编号 | 前提 / 场景 | 用户动作或触发事件 | 可观察的预期结果 |
|---|---|---|---|
| AC-01 | 用户进入日志频道 | 打开 /logs，切换标签页 | 默认显示置顶“任务运行看板”；原服务器日志、任务日志保持可用；不新增顶级导航；看板 tab 可通过 URL 保持 |
| AC-02 | 聚合快照返回五类任务 | 查看首屏 | 显示价格同步、完整性检查、提醒评估、汇率同步、再平衡分发五张卡及总览；同时可辨识运行态、数据态、最近运行和快照时间；总览不把未知数据算成正常 |
| AC-03 | 目标日存在应采价格 | 查看价格卡及缺失清单 | 展示后端有效目标市场日、expected/fetched 与进度；全部齐全为绿，部分缺失为黄，全部缺失为红；缺失标的与快照一致，不由 SUCCEEDED 或 successCount 替代 |
| AC-04 | 休市、未到同步时点或应采为零 | 查看价格卡 | 沿用聚合接口有效目标日及说明；不因日历日期误报缺价；零目标显示明确灰色状态，不出现 NaN 或溢出进度 |
| AC-05 | 完整性、提醒或汇率结果已就绪 | 查看对应卡片 | 真实显示完整性缺口/跳过、提醒命中与失败、各币种已记录的同步结果；零提醒属正常；不可获得的结果明确为未知，不伪造逐币种成功或把运行成功当作数据验证 |
| AC-06 | 再平衡父任务与逐组合结果已就绪 | 查看再平衡摘要 | 到期分母取父任务结果；区分到期、生成成功、失败、未超阈无需生成；异常组合及原因可在摘要中辨识，不由零记录反推未到期；本次不要求独立详情页 |
| AC-07 | 无运行记录或结果契约未就绪 | 查看相关卡片 | 显示无记录/数据契约未就绪及未知数据态；不显示伪造完成度或“全部正常”；结果补齐并刷新后可展示真实数据，最终验收不能跳过完整契约场景 |
| AC-08 | 任务被跳过，或遗留 RUNNING 已超过读侧僵尸阈值 | 查看记录对应的运行态 | 已持久化的跳过结果显示为跳过并可解释原因；僵尸不显示为仍在正常运行。跳过记录可重新查询，不能仅存在于执行返回值 |
| AC-09 | 看板显示状态 | 查看颜色、文字及图例 | 绿/黄/红/灰表示系统好/关注/坏/未知或跳过，并有文字或图标区分；与行情红涨绿跌隔离，不改变行情页配色 |
| AC-10 | 首次进入、用户刷新或请求失败 | 加载/刷新看板 | 打开时读取快照；手动刷新更新数据和时间，不自动轮询；加载、空态和错误可辨识；局部数据错误不使可用卡片失效；请求失败不伪装成功或整页白屏 |
| AC-11 | 用户查看看板及原日志 | 检查页面行为和请求 | 无执行、撤销、重做、手动触发、编辑阈值等写入口；/logs 子树无写服务调用；读取不触发任务或写集合，原日志功能无回归 |
