# client 使用手册

> **前端（界面）操作的单一归属文档**：功能怎么用、界面手动入口、业务数据口径、常见问题。
>
> 系统怎么安装/启动、环境变量、安全边界见 [系统部署手册](./DEPLOYMENT.md)；
> 后端 API 手动端点见 [server 使用手册](./SERVER.md)；定时任务与数据质量见 [cron-worker 使用手册](./CRON_WORKER.md)。

---

## 1. 这是什么

PortoMind 是自托管的个人/家庭投资组合管理工具，部署在自己的家庭服务器或可信局域网内，**不连券商、不自动交易**。它帮你：

- 记录所有真实买卖与分红，自动按**移动平均成本法**算出持仓、盈亏与持仓历史；
- 每天自动同步资产最新价（美股/加股/A股/场外基金/港股）；
- 为每个组合设定**目标配置**（资产级或大类级），偏离超阈值时给出**再平衡建议**（人工确认才执行）；
- 用**提醒规则**在到价、浮亏、漂移、52 周新高新低、估值分位等条件下产生站内通知；
- 以 **RMB 为基准**汇总全家庭资产（CNY/USD/CAD/HKD 分桶展示）。

安全边界：无登录体系，仅限可信网络访问；再平衡只生成建议，永不自动下单。完整说明见 [系统部署手册](./DEPLOYMENT.md) §「安全边界」。

> 数据每天由 **cron-worker** 自动更新（价格/完整性/提醒/汇率/再平衡分发）。自动任务时间表与手动 CLI 见 [cron-worker 运维手册](./CRON_WORKER_OPS.md)；界面上也可随时手动触发（见 §4）。

## 2. 访问前端

前端地址（本地开发）`http://localhost:5173`，生产由 Nginx 提供 `client/dist/` 静态产物。
前端经 `VITE_API_URL`（需带 `/api` 前缀，如 `http://localhost:8080/api`）连接后端。

系统尚未运行？安装、依赖、环境变量、基线数据、启动方式见 [系统部署手册](./DEPLOYMENT.md) §「本地开发搭建」与 §「生产部署」。

## 3. 功能模块使用

### 3.1 资产与价格

**登记资产**（`资产管理` → 添加资产）：代码唯一且大写（如 `0700.HK`、`600519.SS`、`VTI`、`005827`），必填市场/币种/证券类型。可选填：

- **大类**（股票类/债券类/黄金类/现金类）：与证券类型正交（黄金 ETF 的证券类型是 ETF、大类是黄金类）。大类用于「大类级目标配置」与组合页的家庭分桶归类，**新资产务必顺手分类**。
- **上市日期 launchDate**：用于完整性检查推断应有交易日数，建议填写（当前只能直接改数据库，见 [cron-worker 开发文档](../dev/CRON_WORKER_DEV.md) §6）。
- 启用 active：控制可否用于交易与行情同步；关注 watchlist 仅展示偏好。

**看行情**（`价格`）：今日价格页按资产看最近一条价格，可指定日期回查、手动刷新；点资产进历史页看折线图与每日价格表格（年月筛选）。

### 3.2 组合

**创建组合**（`组合管理` → 添加组合）：名称必填；类型（活钱/稳健/长期）是风险定位；账户类型（tiantian/xueqiu/tfsa/rrsp/resp/taxable/other）是真实账户载体（天天基金/雪球/TFSA/RRSP/RESP…）。币种是记账币种，只在本组合内使用。

**目标配置**（**`组合管理` → 编辑组合 → 表单内「目标配置」区**）：二选一模式——

- **资产级**：为每个 symbol 设目标比例（合计必须精确 100%）；
- **大类级**：为 equity/bond/gold/cash 设目标比例。再平衡建议会自动按「类内持仓市值占比」摊分到具体资产（保持大类内部结构）；某大类无持仓时给 `CLASS_NO_POSITIONS` 警告、未分类资产计 `UNCLASSIFIED` 偏离——**使用大类目标前请先把资产的大类补全**。

> 目标配置目前**只在组合编辑表单内维护**；组合详情页只有 `持仓概览 / 持仓历史 / 再平衡 / 交易记录` 四个页签，没有独立的「目标配置」页。

**归档**（编辑组合勾选）：归档 ≠ 删除，数据完整保留，仅从默认列表与自动再平衡调度中隐藏。

**组合列表页的家庭汇总区块**（`组合管理` → `组合列表`，自上而下）：

1. **币种分桶**：USD / CAD / CNY / HKD 四卡，显示各币种原币种金额与 RMB 折算值（非 CNY 附当日汇率）；
2. **组合占比条**：一条堆叠条 + 图例，点图例项直达该组合的「持仓概览」；折算不完整的组合不占条宽，图例标「折算不完整」；
3. **组合卡片**：常规列表（受「显示已归档」开关控制）；
4. **最近交易**：仅 5 条预览，`查看全部 →` 跳「全部交易」页；
5. **最近再平衡**：最近 10 条，标注自动/手动与状态；
6. **家庭汇率**：默认收起，展开后可「同步汇率」或手动录入。

> 分桶与占比**固定只含未归档组合**，与「显示已归档」开关无关；开关打开后卡片会比占比多，属预期口径差异（页面已常显一行说明）。

### 3.3 交易

交易是**组合的子资源** —— 记在哪个组合里，就在哪个组合里维护。

**组合内维护**（组合详情 → `交易记录` 页签）：`新建交易` / `导入 CSV` / 行内 `编辑`、`删除`。所属组合由页面上下文锁定，不需要也不能手选，杜绝记到别的组合。字段：

- **交易类型**：买入 / 卖出 / **现金分红**（份额×每股分红计现金，不进持仓）/ **分红再投**（等价买入转增持仓）；
- **费用**：买入成本含费、卖出净得扣费（影响之后的持仓与已实现盈亏）；
- 卖出超过当日可用持仓会被拒绝（提示 symbol 与日期）；
- **A股买入**（沪/深）非 100 股整数倍时仅提示、不阻止。

**CSV 批量导入**（组合详情 → `交易记录` → `导入 CSV`）：目标组合已由入口锁定，只需选 CSV 文件（天天基金/雪球导出可直接识别列名，也可手动调整映射）→ 预览前 50 行 → 确认导入。任何一行数据非法或导致超卖时**整批回滚**；重复记录**本应**自动跳过，但该去重当前**不生效**（同一文件重复导入会重复入库，见 TASK-046），导入前请自行确认。每批最多 500 行。

**跨组合查账**（左侧 `组合管理` → `全部交易`）：一次列出所有组合的流水，含「组合」列，可按组合与资产代码筛选、分页；点组合名可跳回该组合的 `交易记录` 页签。此页**只读**——新增与导入请回到所属组合内完成。

### 3.4 再平衡

组合详情 → 再平衡页签：

1. **阈值检查**：绝对偏离（默认 5%）、相对偏离（默认 10%）、时间间隔（默认 60 天）独立启停，任一触发即提示再平衡；
2. **生成建议**：输入本次可投入现金与费率假设（固定费/比例费/卖出税率），系统给出先卖后买的清单（含费用与调整后比例）；
3. **执行**：确认后仅在本系统内生成交易流水（不连券商）；后悔可**撤销**（自动生成反向交易）、撤销后可**重做**。
4. **AUTO 调度**：按 daily/weekly/monthly 自动检查并生成待确认建议（由 cron-worker 触发，见 [cron-worker 开发文档](../dev/CRON_WORKER_DEV.md) §3），**永不自动执行**；触发时产生站内通知（首页「待处理提醒」可见）。

大类级目标组合的建议同样走此流程，建议上标注 `assetClass`。

### 3.5 待处理提醒

入口：首页（`Dashboard`，标题「家庭总览」）——顶部是家庭总资产卡（RMB 折算，点击进入组合管理），下方「待处理提醒」即原通知中心；右上角铃铛显示未读总数。

**规则管理**（`提醒规则`）：支持 8 种规则类型——

| 类型 | 参数 | 触发条件（严格比较，恰等于不触发） |
|---|---|---|
| 价格高于/低于 | 价格阈值 | 最新价 > / < 阈值 |
| 盈亏比例 | ±百分比 | 浮盈超 +x% / 浮亏超 -x% |
| 组合偏离 | 偏离阈值 % | 组合漂移触发（复用组合卡片徽标口径） |
| 人工信号 | 方向+理由+有效期 | 有效期内常显，过期自动归档 |
| 52 周新高/新低 | 回看天数（默认 365） | 最新价突破历史（不含今日）最高/最低 |
| 估值分位 | 指数代码+PE/PB+阈值+方向 | 分位 > 阈值（高估）/ < 阈值（低估） |

通用：作用域（资产级=绑资产代码，组合级=绑组合）、静默天数 cooldown（默认 7 天，同规则触发后静默期内不重复）、启停开关。每规则可查看触发历史。

**估值分位数据**：`valuation_percentile` 规则需要先有分位数据——用你的估值计算工具算出后，通过 [server API](./SERVER.md) 录入（`PUT /api/valuations/<CODE>/<METRIC>`，body `{value, percentile}`）；没有数据时规则静默不触发。

通知中心：未读/全部切换、按组合筛选、标记已读/忽略；signal 类事件常显直至过期或手动处理；点击事件直达资产历史页或再平衡页。`立即评估` 按钮可随时手动跑一次评估。

### 3.6 家庭总资产

入口：**首页**（`Dashboard`，标题「家庭总览」）顶部的总资产卡。以 **RMB 折算**展示家庭总资产，点击卡片进入组合管理。

- 折算口径：组合内保持原币种记账，折算只发生在家庭层；某币种缺最新价或无汇率时该组合标「折算不完整」且**不计入总额**（宁可少报不可错报）。
- 分币种金额、组合占比、最近交易与再平衡、汇率管理都在 `组合管理 → 组合列表` 页（见 §3.2）。
- **汇率**：页面底部的「家庭汇率」面板，显示最新汇率（1 外币 = ¥）。每日 09:30 由 cron-worker 自动同步（见 [cron-worker 产品介绍](./CRON_WORKER_PRODUCT.md) §2.4）；同步失败或想手动修正时，选币种填汇率「录入」（手动数据以 `manual` 标记）。

### 3.7 日志

`日志`：按日期/级别查询服务日志与后台任务日志。任务每次运行记录在 `taskruns` 集合，查询与排障方法见 [cron-worker 运维手册](./CRON_WORKER_OPS.md) §7。

## 4. 界面上的手动入口

| 位置 | 操作 | 作用 |
|---|---|---|
| Dashboard / 待处理提醒 | **立即评估** | 手动跑一次提醒规则评估（同 server `POST /api/alerts/evaluate`） |
| 价格 → 今日价格 | **刷新** / **查看历史** | 手动拉取当日价格 / 进入某资产历史页 |
| 组合详情 → 再平衡 | 检查 / 生成建议 / 执行 / 撤销 / 重做 | 再平衡闭环 |
| 组合管理 → 组合列表 → 家庭汇率 | **同步汇率** / **录入** | 手动同步或录入汇率（同 server `POST /api/family/fx/sync`） |
| 组合详情 → 交易记录 | 新建 / 编辑 / 删除 / 导入 CSV | 维护该组合的交易流水（组合已锁定） |

> 命令行入口（手动同步、完整性检查、历史回补）见 [cron-worker 运维手册](./CRON_WORKER_OPS.md) §6；API 端点见 [server 使用手册](./SERVER.md) §5。

## 5. 业务数据口径

- 交易是唯一事实来源：持仓由交易按时间重放推导（移动平均成本），改/删历史交易会重算其后所有持仓；
- 不同币种**不在组合层合计**，仅家庭层按最新汇率折算 RMB；
- 提醒/汇率/估值的数据都在各自集合中维护，删除资产或组合不会级联删除事件与汇率记录；
- 事件不可删除（审计），只能标记已读/忽略。

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 某资产无最新价 | 休市日跳过属正常；若连跌多日，查 `taskruns` 的 `failures[]`（provider/timeout 分类，见 [cron-worker 运维手册](./CRON_WORKER_OPS.md) §7） |
| 提醒规则不触发 | 检查是否启用；`valuation_percentile` 需先录入分位数据（见 §3.5）；52 周新高需该资产有 ≥1 条历史价 |
| 家庭总资产/分桶金额为「—」或标「折算不完整」 | 某币种缺最新价或无汇率——同步价格/录入汇率即可 |
| 导入 CSV 整批失败 | 先看预览中红字行；常见为日期格式或方向值无法识别（映射列可手动调整） |
| 组合不参与自动再平衡 | 该组合已归档，或 cron-worker 未运行 / `SCHEDULER_ENABLED=false`（见 [cron-worker 运维手册](./CRON_WORKER_OPS.md) §5/§8） |
